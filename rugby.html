National-team rugby union only — club competitions (Top 14, URC, Gallagher Prem, Super Rugby, etc.) aren't included here. Test Matches is a catch-all for internationals outside the other five competitions, so it mixes tier-1 nations with much smaller ones — the ★ stars are there to help surface the real fixtures. Windows are clustered from the real fixture list the same way club soccer matchdays are — grouped by the natural gap between kickoffs, since these competitions don't run on a fixed weekly schedule. Some tabs will be empty most of the time (the World Cup and the Lions Tour only happen every 4 years) — that's expected, not an error. Schedule data is fetched fresh every visit rather than cached, since these calendars keep filling in over time. Records are plain W-D-L, tallied from completed windows before the one you're viewing within that same competition — not converted to a points table, since bonus-point scoring differs by competition. Records are hidden behind each team's own 👁 the same way as the other boards. ★ stars use broadcast slot, competition prestige, how close the two teams' records are so far, and a close final score (within a converted try, 7 points) or a result against the run of form. 📑 / ☐☑ / ♥ work the same as the other boards, but are kept on their own separate list — not merged into the shared Watchlist page. Data via ESPN's public scoreboard endpoints.
